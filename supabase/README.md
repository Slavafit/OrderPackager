# Настройка Supabase

1. Откройте **SQL Editor** проекта Order Packer.
2. Вставьте целиком содержимое `setup.sql` и нажмите **Run**.
3. В таблице результата появится `sync_token`. Он показывается только при первом запуске.
4. Добавьте токен в локальный `local.properties`:

   ```properties
   SUPABASE_SYNC_TOKEN=полученный_токен
   ```

`local.properties` исключён из Git. Публичный ключ Supabase и секрет синхронизации не
попадают в репозиторий. Таблица заказов закрыта RLS и доступна приложению только через
две RPC-функции, проверяющие токен.
