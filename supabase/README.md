# Настройка Supabase

Для новой базы сначала выполните `setup.sql`. Затем создайте пользователя в
**Authentication → Users** и выполните `migrate_to_auth.sql`, указав в нём UID этого
пользователя.

Для синхронизации справочника клиентов после основной настройки один раз выполните
`add_clients_sync.sql` в **SQL Editor**. При первой успешной синхронизации существующие
клиенты с устройства будут загружены в облако. Если облачный список уже есть,
уникальные локальные клиенты добавятся без дублирования.

Для синхронизации циклического списка затем один раз выполните
`add_cyclic_items_sync.sql`. Порядок позиций сохраняется; на свежей установке
облачный список заменяет встроенные демонстрационные записи.

Приложение показывает экран входа и использует Supabase Auth. Пароль не сохраняется:
локально хранится только обновляемая сессия. Таблица заказов защищена RLS и каждый
пользователь видит только строки со своим `owner_id`.
