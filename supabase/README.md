# Настройка Supabase

Для новой базы сначала выполните `setup.sql`. Затем создайте пользователя в
**Authentication → Users** и выполните `migrate_to_auth.sql`, указав в нём UID этого
пользователя.

Приложение показывает экран входа и использует Supabase Auth. Пароль не сохраняется:
локально хранится только обновляемая сессия. Таблица заказов защищена RLS и каждый
пользователь видит только строки со своим `owner_id`.
