Política de privacidad de Order Packer

Fecha de entrada en vigor: 29 de octubre de 2026

Order Packer ayuda a crear e imprimir etiquetas de almacén y a guardar información sobre pedidos empaquetados.

Datos que se tratan

La aplicación trata el correo electrónico del usuario, el apellido del cliente, el número de caja, el número de lote, el contenido del pedido, los nombres de posiciones de la lista cíclica, las dimensiones de la caja, el peso y la fecha de embalaje. La aplicación no guarda la contraseña del usuario.

Finalidad del tratamiento

Los datos se utilizan para la autenticación, el funcionamiento de la aplicación, la creación de etiquetas e informes, la sincronización, las copias de seguridad y la restauración de pedidos. Los datos no se utilizan con fines publicitarios ni se venden a terceros.

Almacenamiento y transferencia

Los datos se guardan localmente en el dispositivo y pueden transmitirse mediante una conexión HTTPS cifrada a Supabase. El acceso a los pedidos y al directorio de posiciones almacenados en la nube está limitado mediante autenticación y políticas de seguridad a nivel de fila (RLS).

Conservación y eliminación

Los datos se conservan hasta que el propietario de la aplicación los elimina. Los datos locales pueden eliminarse desde el dispositivo. Para solicitar la eliminación de los datos almacenados en la nube, contacte con el desarrollador.

Seguridad

Se aplican medidas técnicas razonables, incluido el cifrado durante la transmisión y el control de acceso. Ningún método de almacenamiento o transmisión garantiza una seguridad absoluta.

Desarrollador y contacto

Cambios en esta política

Si cambia el tratamiento de los datos, esta política se actualizará y la nueva fecha de entrada en vigor se indicará tanto en la aplicación como en esta página.

Order Packer Privacy Policy

Effective date: October 29, 2026

Order Packer helps create and print warehouse labels and store information about packed orders.

Data we process

The application processes the user's email address, client surname, box number, batch number, order contents, cyclic-list position names, box dimensions, weight, and packing date. The application does not store the user's password.

How data is used

Data is used for authentication, application functionality, creating labels and reports, synchronization, backup, and order restoration. Data is not used for advertising and is not sold to third parties.

Storage and transfer

Data is stored locally on the device and may be transferred to Supabase over an encrypted HTTPS connection. Access to cloud orders and the positions directory is restricted by authentication and Row Level Security (RLS) policies.

Retention and deletion

Data is retained until it is deleted by the application owner. Local data can be removed from the device. To request deletion of cloud data, contact the developer.

Security

Reasonable technical safeguards are used, including encryption in transit and access controls. No storage or transmission method can guarantee absolute security.

Developer and contact

Changes to this policy

If data processing changes, this policy will be updated and the new effective date will be shown in the application and on this page.

Политика конфиденциальности Order Packer

Дата вступления в силу: 29 октября 2026 г.

Order Packer помогает создавать и печатать складские этикетки и сохранять сведения об упакованных заказах.

Какие данные обрабатываются

Приложение обрабатывает адрес электронной почты пользователя, фамилию клиента, номер бокса, номер партии, состав заказа, названия позиций циклического списка, размеры коробки, вес и дату упаковки. Приложение не сохраняет пароль пользователя.

Для чего используются данные

Данные используются для авторизации, работы приложения, формирования этикеток и отчётов, синхронизации, резервного копирования и восстановления заказов. Данные не используются для рекламы и не продаются третьим лицам.

Хранение и передача

Данные хранятся локально на устройстве и могут передаваться по защищённому HTTPS-соединению в Supabase. Доступ к облачным заказам и справочнику позиций ограничен авторизацией и правилами Row Level Security (RLS).

Срок хранения и удаление

Данные хранятся до их удаления владельцем приложения. Локальные данные можно удалить с устройства. Для запроса на удаление облачных данных свяжитесь с разработчиком.

Безопасность

Используются разумные технические меры защиты, включая шифрование при передаче и разграничение доступа. Ни один способ хранения или передачи не гарантирует абсолютную безопасность.

Разработчик и контакты

Разработчик: Viacheslav Fitlin. Контакт по вопросам конфиденциальности: Telegram @Slavafit.

Изменения политики

При изменении обработки данных политика будет обновлена, а новая дата вступления в силу будет указана в приложении и на этой странице.
