# Политика конфиденциальности Order Packer

Дата вступления в силу: 26 октября 2026 года

Разработчик: Fitlin Viacheslav

Контакт по вопросам конфиденциальности: Telegram [@Slavafit](https://t.me/Slavafit)

Order Packer помогает создавать и печатать складские этикетки и сохранять сведения
об упакованных заказах, формировать отчёты и синхронизировать данные.

## Какие данные обрабатываются

Приложение может обрабатывать адрес электронной почты, фамилию клиента, номер бокса,
номер партии, сведения о содержимом заказа, размеры коробки, вес и дату упаковки.
Пароль используется только для входа через Supabase Auth и не сохраняется приложением.
Данные не используются для рекламы и не продаются третьим лицам.

## Для чего используются данные

Данные используются для работы приложения, авторизации, формирования этикеток и отчётов,
синхронизации, резервного копирования и восстановления заказов.

## Хранение и передача

Данные хранятся локально на устройстве и могут передаваться по защищённому HTTPS-
соединению в облачную базу Supabase. Доступ к облачным данным ограничивается
правилами Row Level Security (RLS). Supabase обрабатывает данные как поставщик
облачной инфраструктуры.

## Срок хранения и удаление

Данные хранятся до их удаления владельцем приложения. Для запроса на удаление облачных
данных свяжитесь с разработчиком через Telegram [@Slavafit](https://t.me/Slavafit).

## Безопасность

Используются разумные технические меры защиты, включая шифрование данных при передаче
и разграничение доступа к облачным данным. Ни один способ хранения или передачи не
обеспечивает абсолютной безопасности.

## Изменения политики

При изменении политики её актуальная версия публикуется по тому же адресу с новой
датой вступления в силу. Копия политики также доступна внутри приложения в разделе
«Настройки».

Для Google Play опубликуйте файл [`privacy-policy.html`](privacy-policy.html) на
публичной HTTPS-странице и укажите её адрес в Play Console и параметре
`PRIVACY_POLICY_URL` файла `local.properties`.
